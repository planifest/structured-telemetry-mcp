## Deployment Procedure

1. Merge PR to `main` — CI passes on all 6 matrix combinations
2. Run `npm run build` locally to produce updated bundles
3. Stop the running daemon (`Stop-Service structured-telemetry-mcp` or equivalent)
4. Deploy updated bundles (copy `server-http.bundle.mjs`, `cli.bundle.mjs`, `server.bundle.mjs`)
5. Restart daemon (`scripts/deploy.ps1` or `Start-Service structured-telemetry-mcp`)
6. Verify daemon is reachable: `npx structured-telemetry-mcp doctor`
7. Run post-deployment truncation (human-only):
   - Open an elevated shell (Run as Administrator / sudo)
   - Execute `scripts/DELETE-ALL-PRODUCTION-RECORDS.ps1` (Windows) or `scripts/DELETE-ALL-PRODUCTION-RECORDS.sh` (Unix)
   - Follow interactive prompts; confirm deleted row count is reported

| Daemon fails to start after deployment | Check `server-http.bundle.mjs` is present; check port 3741 is not in use |
